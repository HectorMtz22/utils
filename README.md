# utils

A multi-project repository. Each top-level directory is a self-contained Python project with its own `pyproject.toml` and dependencies.

## Projects

- [`pdf_crop/`](pdf_crop/) — CLI + TUI to extract page ranges from PDFs.
- [`music-lyrics/`](music-lyrics/) — script to fetch synced/plain lyrics from lrclib.net for a local FLAC/MP3 library.
- [`thermal-qr/`](thermal-qr/) — shell script to print a QR code of a URL/text to the macOS default printer.
- [`pxe-boot/`](pxe-boot/) — macOS CLI to PXE-boot a PC on the LAN (netboot.xyz or local ISO).
